---
name: grill-me
description: Interview the user one question at a time to surface and settle every open decision behind a plan, design, or idea, until both sides share the same understanding. Use when the user wants their thinking stress-tested, or wants a plan pinned down before any work starts.
argument-hint: The topic we want to share an understanding of.
---

Interview the user relentlessly about every aspect of the topic until we reach a shared understanding. Walk down each branch of the decision tree, resolving dependencies between decisions one-by-one. For each question, provide your recommended answer.

Ask the questions one at a time, waiting for feedback on each question before continuing. Asking multiple questions at once is bewildering.

Keep an explicit list of the unresolved decisions instead of holding them in your head. Before the first question, enumerate every open decision you can already see, and order them by impact and by which ones other decisions depend on. Each answer tends to close some branches and open others, so revise the list after every answer. A deep branch is exactly where a forgotten decision hides.

If a *fact* can be found by exploring the environment (filesystem, tools, etc.), look it up rather than asking. The *decisions*, though, must be answered by the user. When a fact you looked up bears on the question at hand, state it together with the question, so that the user decides with the evidence already in view rather than from memory.

If you have no more questions to ask, wait for the next prompt without acting on the plan. The user may restart this skill to refine it further.
